# haste-inspector

Replay inspector for Dota 2, Deadlock, and CS2 replays.

Forked from [blukai/haste-inspector](https://github.com/blukai/haste-inspector).

## Changelog

- Changed backend to [source2-demo](https://github.com/Rupas1k/source2-demo) (CS2 support + fixes).
- Changed project layout.
- Small UI improvements and fixes.

## Original README

Dev tools for dota 2 and deadlock (the game) replays. Powered by
[haste](https://github.com/blukai/haste) replay parser.
